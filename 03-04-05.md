# 04: Types

- Numbers and Sentences are not meant to be, and programs, like a xenophobe, will scream at you

```python
x = "Hello, World!"
y = "42"
z = max(x, y) # Integer and String? NOT IN MY HOUSEHOLD
```

- You can determine the type of an object by calling `type()` function on it
```python
print(type("Hello, World!"))
print(type(34))
print(type(1.234))
```
```
<class 'str'>
<class 'int'>
<class 'float'>
```

- As you can see, there is `int` and `float`. These two can actually mix, double standards. Float takes custody of the child
```python
x = 1.2
y = 2
z = x * y
print(x, y, z)
print(type(x), type(y), type(z))
```
```
1.2 2 2.4
<class 'float'> <class 'int'> <class 'float'>
```

*NOTE:*
 - Sometimes, Python does let you combine strings and numbers using arithmetic operators. The statement `print("hots" * 2)` prints hotshots. Python's rule is that multiplying a string s by an integer n means to put n copies of the string one after another.
